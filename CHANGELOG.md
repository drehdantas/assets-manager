# Changelog

## 2.1.1 — 2026-10-28
- Import folder: works more reliably in Firefox (the hidden folder input stays attached to the page)
- Import folder: picking a folder with no images now explains what to do and offers to download the project as a ZIP to extract there, instead of doing nothing

## 2.1.0 — 2026-10-28
- **Folder sync in any browser** (Firefox, Safari…): *Import folder* reads a whole folder tree into projects/folders, and *Download changes* returns new or modified files as a ZIP with the same structure
- "Connect computer folder" only shows in browsers that support it
- After opening a project, the first folder with files is selected
- ☕ Support link (Buy Me a Coffee) in the app and README

## 2.0.0 — 2026-10-28
- Export animations as **GIF, MP4 (H.264) and WebM (VP9)**, at sprite scale or with **social media presets**; length always a whole number of loops
- **Manual crop editor** in Trim (draw, move, resize, numeric input, apply to all)
- **Background removal**: flood from edges or global color, tolerance, soft edges, halo cleanup, eyedropper
- New **Batch** tool: rename with patterns/numbering/find & replace/case styles, optional convert and resize
- **Undo / redo and history** for library operations and tool edits
- Folder **file counts** and **"new files"** indicators; NEW badge on cards
- Library actions grouped in a **Send to ▾** menu (tools + move to folder)
- **Rename project**
- Interface fully in **English**
- Removed the "Merge sheets" tool
- Installable app (PWA) with offline support; single-file build

## 1.0.0 — 2026-10-28
- Library with projects and folders (browser storage or computer folder)
- Sprite Sheet maker with reorderable frames, trim, padding, alignment, PNG + JSON export
- Trim tool, Compress tool with quality-based recommendation, Animation player
